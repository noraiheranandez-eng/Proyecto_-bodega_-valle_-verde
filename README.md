# Proyecto Bodega - Distribuidora Valle Verde - Clase 5 Rosa
Basado en Manual AIF_C05 v3.2 - Manual de Procesos de Operaciones

## Propuesta de Mejora
1. Recepción: Conteo ciego obligatorio, cita 24h antes, tolerancia 30 min, caducidad minima 70%, diferencia max 2% en formato OP-12.
2. Almacenamiento: Zonas A (alta rotacion), B (media), C (baja/quimicos), F (camara fria 4°C), Q (cuarentena). Rotacion FEFO/PEPS, apilado max 4 niveles.
3. Surtido y Embarque: 3 olas diarias 8:00, 11:00, 14:00. Prioridad vencidos primero. Verificacion 100% cuentas clave. Bultos max 25kg, cierre 17:30.
4. Devoluciones: Solo con folio RMA, 5 dias en Zona Q.
5. Inventarios: Ciclicos semanales Zona A y F. Formato OP-07 para incidencias en 4h. Reporte lunes 10:00.

## Formatos Usados
OP-07, OP-12, OP-15, RMA
